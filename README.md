# Sweepfill

Sweepfill™ is a browser extension that keeps a daily checklist of the sweepstakes you follow. It shows what's due today, opens each contest for you to enter, and checks it off once you've entered.

## Installation

Coming soon to the Chrome Web Store and Firefox Add-ons.

## Usage

Check out the [User Guide](USER_GUIDE.md) for information on how to use the extension.
